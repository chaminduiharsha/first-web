# Finexo – Cryptocurrency Website

A modern and responsive cryptocurrency company website built using **HTML, CSS, Bootstrap, and JavaScript**. The website presents cryptocurrency-related services, company information, business advantages, team members, customer testimonials, and contact/subscription sections.

## 📌 Project Overview

**Finexo** is a cryptocurrency-themed company website designed to provide visitors with information about cryptocurrency services and the company.

The website includes a responsive navigation bar, cryptocurrency hero section, service cards, company information, reasons to choose the company, team members, customer testimonials, and a subscription section.

## ✨ Features

* Responsive navigation bar
* Cryptocurrency hero section
* Image carousel/slider
* About Us section
* Cryptocurrency services section
* Currency Wallet service
* Security Storage service
* Expert Support service
* Why Choose Us section
* Expert Management
* Secure Investment
* Instant Trading
* Customer testimonials
* Team members section
* Social media icons
* Email subscription form
* Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and layout
* **Bootstrap** – Responsive design and UI components
* **JavaScript** – Interactive functionality
* **jQuery** – JavaScript functionality
* **Font Awesome** – Icons
* **Owl Carousel** – Sliders and carousels
* **Google Fonts** – Roboto typography

The project imports Bootstrap, Roboto, Font Awesome, Owl Carousel, and custom responsive stylesheets.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/finexo-crypto-website.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.
